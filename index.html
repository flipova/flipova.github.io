Démarrage rapide
Prêt en quelques minutes

Installez Foundation et commencez à construire avec le design system Flipova dès maintenant.

1
Installer la librairie
Via npm, yarn ou pnpm
2
Configurer le provider
Wrappez votre app avec FlipThemeProvider
3
Importer et utiliser
Tous les composants sont disponibles via @flipova/foundation
terminal & App.tsx
# Installer Foundation
npm install @flipova/foundation

# Dans votre App.tsx
import { FlipThemeProvider }
  from '@flipova/foundation';

export default function App() {
  return (
    <FlipThemeProvider>
      // votre app ici
    </FlipThemeProvider>
  );
}
